# 무던한 지도 (Calm Map) — S-DoT 공원 소음 예측

서울 공공 센서(S-DoT)의 실측 소음을 학습한 AI가 송파구 공원·놀이터 5곳의 시간대별 소음을 예측하고, 단순 요일·시간 평균보다 나은지 MAE로 검증했으며, 보호자 조건에 맞는 방문 시간을 근거와 함께 추천합니다.

- 테스트 URL: https://neogeo0701.github.io/calm-map-sdot/
- 2026 AI 라이프 솔루션 챌린지(산업통상부 공고 제2026-614호) 출품작
- 아이디어: 2026 AI 라이프 아이디어 챌린지 수상 후보작 「무던한 지도(Calm Map)」 기반 구현. 아이디어 제안자에게 크레딧이 있으며, 공고에 따라 결과물의 지식재산권은 제안자와 개발자가 50:50으로 공동 소유합니다.

## 무엇을 하나
1. 조건 3개 입력: 소리 크기 민감도, 갑작스러운 소리 민감도(낮음/보통/높음), 요일과 시간대
2. 추천 3곳: 장소 × 시간. `부담 점수 = 가중치(소리 크기) × (예측 소음 수준 − 35dB) + 가중치(갑작스러운 소리) × 예측 돌발 소음 지수`, 가중치 낮음 0.5·보통 1·높음 2. 장소마다 가장 낮은 시간 1개, 점수 낮은 순 3곳. 코드: `public/app.js`의 `score()`, `recommend()`
3. 근거 카드: 센서 위치와 공원까지 거리, 최근 실측값과 측정 시각, 예측값과 모델 오차(MAE), 신뢰도, 단순 평균값
4. 지도: 선정 장소와 센서 위치만(Leaflet + OSM 타일)
5. "이 서비스가 말해주지 못하는 것": 실내 소음, 순간 경적, 소리 종류, 아이별 반응. 진단·보장이 아님

서버·계정·API 키 없이 동작하는 정적 사이트입니다. 예측은 미리 계산해 `public/predictions.json`에 넣었습니다.

### 지표
- 소음 수준 = 시간 평균(dB)
- 돌발 소음 지수 = 시간 최대 − 시간 평균(dB). 평균만으로는 갑작스러운 소리 부담을 설명할 수 없다는 지적에 대한 대응입니다. 1시간 집계라 몇 초짜리 소리의 횟수·종류는 알 수 없습니다.
- 결측은 보간하지 않습니다. 실측이 없는 시간은 학습·평가에서 빠지고 화면에는 "정보 부족"으로 표시합니다.

## 모델과 성능
- AI: LightGBM 회귀(소음 수준, 돌발 소음 지수 각각). 피처: 요일, 시간, 주말, 공휴일, 센서 ID, 같은 시각 기온·습도(S-DoT), 1주 전·2주 전 같은 시각 값, 1주 전 한 주 평균
- 기준: 센서별 요일×시간 평균(학습 구간)
- 분리: 시간순 앞 75% 학습(07-13 ~ 09-24 10시), 뒤 25% 테스트(09-24 11시 ~ 10-18)
- 서비스 조건 평가: 데이터 공개가 1주 늦어 화면의 예측(10-28 ~ 11-03)은 마지막 실측에서 217~384시간 뒤입니다. 그래서 테스트도 학습 끝에서부터 예측값을 다시 입력으로 넣는 재귀 방식으로 하고, 같은 거리(217~384시간 뒤) 구간 MAE를 따로 봤습니다. 미래 기온·습도는 직전 7일 같은 시각 값으로 대신했습니다.

서비스 조건 MAE(dB, 5개 센서, 실측 840시간)

| 대상 | AI | 요일×시간 평균(기준) | 기준 대비 | 직전 4주 평균(참고) | 지난주 그대로(참고) |
|---|---|---|---|---|---|
| 소음 수준 | **1.15** | 4.22 | −72.9% | 1.87 | 1.18 |
| 돌발 소음 지수 | **1.52** | 1.78 | −15.0% | 1.61 | 1.86 |

- 7~8월 주간 평균 소음이 9월 이후보다 최대 15.2dB 높았습니다(매미 등 계절 요인으로 추정, 확인 안 됨). 그래서 전체 기간 평균 기준은 불리한 비교 대상이고, 참고 기준 2개를 함께 적었습니다. **소음 수준에서 AI는 "지난주 그대로"와 0.04dB 차이로 사실상 같습니다.** 돌발 소음 지수는 세 기준 모두보다 낮았습니다.
- 첫 모델(직전 1·24·168시간 값 사용)은 1시간 앞 예측은 잘했지만(MAE 0.95) 재귀로 길게 예측하면 2.03dB로 나빠졌습니다. 피처를 바꾼 개선 1(채택), 학습 센서 확대와 파라미터를 바꾼 개선 2(1.41dB)를 거쳤습니다. 세 설정 중 고르는 데 테스트 구간을 썼으므로(별도 검증 구간 없음) 채택 모델의 수치는 약간 낙관적일 수 있습니다. 전체 기록: `model/metrics.json`, `model/attempts/`, `DECISIONS.md`
- 장소별 신뢰도(서비스 조건 MAE): 1.5dB 미만 높음, 1.5~3.0 보통, 3.0 초과 낮음

## 한계
- 센서 5대, 송파구, 14주. 계절이 바뀌는 시기라 학습 기간 대부분이 테스트 기간과 소음 수준이 다릅니다.
- 센서는 공원 경계에서 0~26m 떨어진 가로등·건물 벽에 있습니다. 공원 안쪽 소리, 실내 소리와 다를 수 있습니다.
- 소리의 종류(사람, 공사, 음악)는 모릅니다. 1시간 최대·평균만 있습니다.
- 사용자 검증(보호자 인터뷰, 실제 방문 결과)은 하지 않았습니다.
- 데이터가 1주 늦게 공개되어 예측이 9~16일 앞입니다. Open API(최근 한 달)를 쓰면 더 짧아질 수 있습니다.

## 다시 만들기
```
pip install pandas numpy lightgbm shapely pyproj openpyxl holidays matplotlib
python pipeline/01_load_sdot.py      # data/raw/S-DoT_NATURE_*.csv → data/processed/sdot_hourly_all.pkl
python pipeline/02_gate.py           # 게이트 판정(센서–공원 거리, 결측률)
python pipeline/03_select_sites.py   # 선정 5곳
python pipeline/04_model.py base && python pipeline/04_model.py try1 && python pipeline/04_model.py try2
python pipeline/05_forecast.py       # metrics.json, 그래프, predictions.json
python -m http.server -d public
```
원본 내려받기: 열린데이터광장 OA-15969 파일 목록의 `S-DoT_NATURE_*.csv`(14주)와 설치 위치정보 xlsx → `data/raw/`. OSM은 `pipeline/02_gate.py` 상단 주석의 Overpass 질의.

# 무던한 지도 (Calm Map) — 공원·놀이터 돌발 소음 예측

> **2026-10-27 업데이트 — AI 우위 주장 철회.** 2024~2026년 기준일 20개로 순차 백테스트를 한 결과, AI(돌발 지수 예측)가 단순한 요일×시간 평균(2024년 이후)보다 추천을 더 잘한다는 근거가 없었습니다(조용한 시간대 적중률 −2.6%p [−7.3, +2.3], 갑자기 커지는 소리 과소예측 +8.2%p [+1.1, +15.2]). 그래서 **지금 화면은 두 값 모두 요일×시간 평균**을 씁니다. AI는 "최근 몇 주만 보는 방법"보다는 나았습니다. 자세한 내용: [BACKTEST_REPORT.md](BACKTEST_REPORT.md). 아래 "모델과 성능" 절은 그 전의 기록입니다.
>
> 예측은 매일 06:10(한국시간) GitHub Actions가 공개 S-DoT 파일로 다시 만듭니다(`.github/workflows/daily.yml`, `pipeline/daily_update.py`, 인증키 불필요). 화면에 예측 생성 시각·마지막 실측·유효기간을 표시하고 지난 날짜·시각은 추천하지 않습니다.

평균 소음만으로는 보이지 않는 '갑작스러운 소리'를 돌발 소음 지수(시간 최대 − 평균)로 정의하고, AI(LightGBM)가 송파구 공원·놀이터 5곳의 시간대별 돌발 지수를 예측합니다. 학습/검증/테스트 3분할로 단순 방법 3개와 비교해 AI가 이긴 부분(돌발 지수)만 AI를 쓰고, 이기지 못한 부분(소음 수준)은 "지난주 그대로"를 씁니다. 보호자 조건에 맞는 방문 시간을 근거와 함께 추천합니다.

- 테스트 URL: https://neogeo0701.github.io/calm-map-sdot/
- 2026 AI 라이프 솔루션 챌린지(산업통상부 공고 제2026-614호) 출품작
- 아이디어: 2026 AI 라이프 아이디어 챌린지 수상 후보작 「무던한 지도(Calm Map)」 기반 구현. 아이디어 제안자에게 크레딧이 있으며, 공고에 따라 결과물의 지식재산권은 제안자와 개발자가 50:50으로 공동 소유합니다.

## 무엇을 하나
1. 조건 3개 입력: 소리 크기 민감도, 갑작스러운 소리 민감도(낮음/보통/높음), 요일과 시간대
2. 추천 3곳: 장소 × 시간. `부담 점수 = 가중치(소리 크기) × (소음 수준 − 35dB) + 가중치(갑작스러운 소리) × 돌발 소음 지수`(두 값 모두 2024년 이후 같은 요일·시간 실측 평균. 방법은 `pipeline/live_config.json`), 가중치 낮음 0.5·보통 1·높음 2. 장소마다 가장 낮은 시간 1개, 점수 낮은 순 3곳. 코드: `public/app.js`의 `score()`, `recommend()`
3. 근거 카드(2층): 맨 위 보호자용 한 줄 요약("소리 크기 보통, 갑자기 커지는 소리 적은 편" — 테스트 기간 실측 3분위 기준: 소리 크기 41·45dB, 갑자기 커지는 소리 3·4dB), 값의 출처 라벨(요일·시간 평균 등 화면 방법)·신뢰도·최근 실측·센서 거리. "자세히 보기"에 평균 오차(MAE), 단순 평균 비교, 부담 점수 계산식, 센서 번호
4. 시간대 대안 추천: 추천 3곳이 모두 "갑자기 커지는 소리 많은 편"(또는 "소리 크기 많은 편")이면 같은 날·앞뒤 하루의 다른 시간대 중 추천 3곳 부담 점수 평균이 가장 낮은 시간대를 안내하고, 누르면 그 조건으로 바뀜
5. 지도: 선정 장소와 센서 위치만(Leaflet + OSM 타일)
6. 예측 생성 시각·마지막 실측·유효기간 표시, 지난 날짜·시각 제외(유효기간이 지나면 경고)
7. "이 서비스가 말해주지 못하는 것": 실내 소음, 순간 경적, 소리 종류, 아이별 반응. 진단·보장이 아님

서버·계정·API 키 없이 동작하는 정적 사이트입니다. 예측은 미리 계산해 `public/predictions.json`에 넣었습니다.

### 지표
- 소음 수준 = 시간 평균(dB)
- 돌발 소음 지수 = 시간 최대 − 시간 평균(dB). 평균만으로는 갑작스러운 소리 부담을 설명할 수 없다는 지적에 대한 대응입니다. 1시간 집계라 몇 초짜리 소리의 횟수·종류는 알 수 없습니다.
- 결측은 보간하지 않습니다. 실측이 없는 시간은 학습·평가에서 빠지고 화면에는 "정보 부족"으로 표시합니다.

## 모델과 성능
- AI: LightGBM 회귀. 피처: 요일, 시간, 주말, 공휴일, 센서 ID, 같은 시각 기온·습도(S-DoT), 지연값(설정 3개: 직전 1·24·168시간 / 1·2주 전 같은 시각 + 1주 전 주간 평균 / 그 설정 + 송파 전체 센서 학습)
- 단순 방법 3개: 요일×시간 평균, 직전 4주 요일×시간 평균, 지난주 그대로(직전 7일 실측 반복)
- 시간순 3분할(소음 수준): 학습 07-13 ~ 09-09 17시(약 8.4주), 검증 09-09 18시 ~ 09-24 10시(약 2.1주), 테스트 09-24 11시 ~ 10-18(약 3.5주)
- 선택 규칙(테스트 전에 확정): 대상별로 **검증** MAE가 가장 낮은 후보를 화면에 씀. 테스트는 학습+검증으로 다시 학습해 대상별 **1회**만 평가
- 평가 조건: 데이터 공개가 1주 늦어 화면 값(10-28 ~ 11-03)은 마지막 실측에서 217~384시간 뒤. 예측값을 다시 넣는 재귀 방식으로 같은 거리의 MAE를 봄(검증 구간은 217~342시간만 포함). 미래 기온·습도는 직전 7일 같은 시각 값으로 대신함

테스트 MAE(dB, 서비스 거리, 5개 센서, 실측 840시간). 모든 방법이 같은 학습 기간(2024-01 이후)·같은 테스트 시간

| 대상 | AI | 요일×시간 평균 | 직전 4주 평균 | 지난주 그대로 | 화면 값 |
|---|---|---|---|---|---|
| 돌발 소음 지수 (장기 이력 계절성 AI) | **1.48** | 1.49(2024~) | 1.61 | 1.86 | AI 예측 |
| 소음 수준 (장기 이력 AI는 미사용) | 1.24 | 2.08(2024~) | 1.87 | **1.18** | 지난주 실측 |

- **AI의 주 기여는 돌발 소음 지수 예측입니다.** 5개 센서의 2024-01 ~ 2026-10(약 34개월) 실측과 계절 피처(월·주차·전년 동기 값)로 다시 학습한 모델입니다(`model/attempts/long_history/`, 규칙은 테스트 전 기록). 지난주 그대로보다 20.4%, 직전 4주 평균보다 7.7% 작지만, **같은 긴 기간 요일×시간 평균과는 0.01dB 차이로 사실상 같습니다**(검증에서는 평균이 근소하게 나음). 개선이 계절 피처 때문인지 긴 학습 기간 때문인지는 구분하지 않았습니다.
- **소음 수준은 AI가 "지난주 그대로"를 넘지 못했습니다**(같은 2024-01 이후 학습 기준: 검증에선 AI가 나았으나 1.19 vs 1.44, 테스트에서 1.24 vs 1.18dB로 못 미침). 그래서 화면은 지난주 같은 요일·시각 실측값을 씁니다. 7~8월 주간 평균 소음이 9월 이후보다 최대 15.2dB 높아(매미 등 계절 요인으로 추정, 확인 안 됨) 장기 평균은 크게 빗나갑니다.
- 이전 판은 개선안을 테스트 구간으로 골랐습니다. 이를 바로잡아 3분할로 다시 검증했습니다(이전 결과는 `model/attempts/_old_2split/`). 전체 기록: `model/metrics.json`, `model/attempts/`, `DECISIONS.md`
- 장소별 신뢰도(화면에 쓰는 방법의 테스트 MAE): 1.5dB 미만 높음, 1.5~3.0 보통, 3.0 초과 낮음

산출물: `model/metrics.json`, `model/feature_importance.png`, `model/test_actual_vs_pred_spike.png`, `model/test_actual_vs_pred_level.png`, `model/sample_predictions_2026-10-28_11-03.csv`, `public/predictions.json`

## 한계
- 센서 5대, 송파구. 돌발 지수는 약 34개월(2025-04~07 등 결측 많음), 소음 수준 비교는 14주 자료 기준입니다.
- 센서는 공원 경계에서 0~26m 떨어진 가로등·건물 벽에 있습니다. 공원 안쪽 소리, 실내 소리와 다를 수 있습니다.
- 소리의 종류(사람, 공사, 음악)는 모릅니다. 1시간 최대·평균만 있습니다.
- 사용자 검증(보호자 인터뷰, 실제 방문 결과)은 하지 않았습니다.
- 검증 구간이 2.1주로 짧아 서비스 거리 중 217~342시간만 검증했습니다.
- 데이터가 1주 늦게 공개되어 예측이 9~16일 앞입니다. Open API(최근 한 달)를 쓰면 더 짧아질 수 있습니다.

## 다시 만들기
```
pip install pandas numpy lightgbm shapely pyproj openpyxl holidays matplotlib
python pipeline/01_load_sdot.py      # data/raw/S-DoT_NATURE_*.csv → data/processed/sdot_hourly_all.pkl
python pipeline/02_gate.py           # 게이트 판정(센서–공원 거리, 결측률)
python pipeline/03_select_sites.py   # 선정 5곳
for a in base try1 try2; do python pipeline/04_model.py $a val; done   # 검증(선택용)
python pipeline/04_model.py try2 test level && python pipeline/04_model.py try1 test spike   # 테스트 1회
python pipeline/05_forecast.py       # metrics.json, 그래프, predictions.json
python -m http.server -d public
```
